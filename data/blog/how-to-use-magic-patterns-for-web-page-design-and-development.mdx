## 简介

[Magic Patterns](https://www.magicpatterns.com/) 是一款 AI 驱动的原型设计工具，主要面向产品团队、设计师与开发者。它支持通过文本提示或截图快速创建交互式 UI mockup，生成的原型可匹配现有设计系统，并输出可用于生产的真实代码。

## 核心能力

- **文本生成 UI**：通过文字描述快速生成界面。

- **截图/网站转换**：将截图或在线网站转换为可编辑 UI。

- **设计系统同步**：同步颜色、字体、间距等设计系统配置。

- **画布组织**：在画布上组织多个页面/屏幕。

- **实时协作**：与团队成员实时协作编辑。

- **预览与分享**：预览并分享交互式原型。

- **代码导出**：直接导出为代码（如 React、Tailwind）或 Figma 文件。

## 示例：构建落地页

### 构建落地页

- 使用以下提示词构建落地页：**A landing page showcasing personal work and interests. Japanese-style.**

![](https://substack-post-media.s3.amazonaws.com/public/images/98749320-9108-4432-a58c-56764436dc3e_3840x1692.png)

- 你也可以通过截图、Figma 导入或网站导入来构建页面。
- 可配置用于构建网页的 UI 库，例如 shadcn、chakra。

### 生成结果

![](https://substack-post-media.s3.amazonaws.com/public/images/04f4d47e-a2ec-4d99-8c46-355293967385_3840x1692.png)

### 继续优化

- 选中需要优化的区域，使用提示词「**Change button title to Contact us**」。

![](https://substack-post-media.s3.amazonaws.com/public/images/ac73309a-0a8a-4f25-a75a-05b7becb1dcf_3840x1692.png)

### 优化结果

- 下图为优化后的效果；优化完成后，可在新标签页中预览。

![](https://substack-post-media.s3.amazonaws.com/public/images/af6c3346-d268-4f03-9b45-99279e2d7f41_3840x1692.png)

### 创建组件

- 选中 **Contact us** 按钮，将其创建为组件。

![](https://substack-post-media.s3.amazonaws.com/public/images/65772eb8-a6b4-4e28-bd89-f0f523b7556b_3840x1692.png)

### 复用组件

- 使用已有组件创建新页面。

![](https://substack-post-media.s3.amazonaws.com/public/images/12df0eba-5600-425d-b4ab-be64aa430ecd_3840x1692.png)

### 部署至自定义域名

- 为域名添加 DNS 记录，即可直接访问。

![](https://substack-post-media.s3.amazonaws.com/public/images/544198d1-f9bd-48cd-99b7-1a2b21314076_3840x1692.png)

### 导出结果

- 可将结果导出或同步至 [Figma](https://www.magicpatterns.com/docs/documentation/get-started/figma-plugin) / GitHub / Code Zip / LLM Prompt。
- 也可 Fork 当前项目，系统将创建一个相同的新项目。

![](https://substack-post-media.s3.amazonaws.com/public/images/457075b7-7468-4e1c-b59f-79bfe64e42c3_3840x1692.png)

## 更多功能

## 总结

Magic Patterns 是一款强大的 AI 原型设计平台，可将文本或截图转化为精致、可导出代码的 UI：

- 支持从提示词到成品的快速迭代，并匹配设计系统。
- 支持实时协作，可直接导出至 Figma 与前端框架。
- 提供画布编辑、组件复用、自定义域名部署等完整工作流。
